## How to turn the site on (one-time)
1. Open: https://github.com/lydanynom/lyd-notes/settings/pages
2. Under **Build and deployment** → Source → choose **Deploy from a branch**
3. Branch: `main`  /  Folder: `/ (root)`
4. Click **Save**

Wait ~60 seconds. The site is live.
